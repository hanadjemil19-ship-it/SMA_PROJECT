# SMA_PROJECT
This project implements a Multi-Agent System (SMA) using JADE to simulate and manage emergency responses. It coordinates various units (Ambulances, Fire Trucks, Police) to handle emergencies efficiently.
🛠️ Technologies Used
Java
JADE (Java Agent DEvelopment Framework)
Maven (pom.xml)
🤖 Agents Included
DispatcherAgent: Receives and assigns emergencies.
AmbulanceAgent, FireTruckAgent, PoliceAgent: Respond to specific emergencies.
HospitalAgent & MedicalCoordinatorAgent: Handle medical logistics.
TrafficControllerAgent: Manages route clearing.
🚀 How to Run
Clone the repository: git clone https://github.com/hanadjemil19-ship-it/SMA_PROJECT.git
Ensure Java JDK is installed.
Run the project using Maven or via your IDE (IntelliJ/Eclipse) using the jade.jar library.
